# Custos e operação

Execução local não necessita serviços pagos ou API. Hospedagem estática comercial, domínio e tráfego têm preços dependentes do fornecedor; não foi contratado plano nesta tarefa. Ferramentas de desenvolvimento estão fixadas no lockfile.

IA está desativada. Banco, autenticação e observabilidade não foram provisionados. Operação futura com dados sensíveis exige orçamento para auth, backend, banco, retenção, recuperação, logs minimizados, revisão de segurança e jurídico. Notícias, B3, mercados globais e preços de varejistas: a cotar; não há orçamento confirmado nem direito de redistribuição presumido.

Publicar a nuvem de desenvolvimento salva a configuração e filesystem pelo produto; não implanta o site na internet nem mantém processos vivos. Reinicie com npm run dev. Para produção estática, servir dist com CSP, X-Content-Type-Options, Referrer-Policy e frame-ancestors; habilitar HTTPS e só então HSTS apropriado. Não usar o servidor local como API financeira.
