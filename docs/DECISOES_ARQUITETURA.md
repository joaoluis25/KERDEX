# Decisões

Reusar o Beta 2 parcial reduz risco de perder marca, traduções e comportamento já existente. O Beta 1 não é a base matemática: mistura períodos e valores flutuantes. Mantidos módulos de finanças, estado, tradução, UI e interação com correções locais verificáveis. Não se afirma leitura linha a linha nem pentest.

Nesta etapa escolheu-se app estático sem servidor de dados para não simular autenticação ou isolamento inexistentes. Node serve arquivos públicos específicos; dependências são apenas de desenvolvimento. Centavos BRL permanecem inteiros; idioma não converte moeda. Datas civis são strings YYYY-MM-DD; rótulos usam UTC para não mudar o dia.

O documento recente de marca tem prioridade visual sobre o briefing antigo que sugeria apenas wordmark. Reutilizados os derivados de símbolo, ícones e banner fornecidos no parcial. Sem redesenho de marca ou imagens de terceiros.

O pedido de montagem amplia a tarefa anterior de onboarding e autoriza criação de código. Nenhum arquivo existente de licença ou atributos foi removido. Não houve push, publicação, worktree ou alteração de histórico.

Próxima migração: componentes TypeScript com estado encapsulado e schema compartilhado, mantendo testes financeiros. React/Next não foi adicionado apenas para declarar modernização; SSR/SSG e tipagem integral continuam pendentes.
